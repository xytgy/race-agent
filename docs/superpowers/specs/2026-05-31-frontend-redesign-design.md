# RaceAgent 前端视觉重设计

## 1. 目标

对 RaceAgent 的 Streamlit 前端进行整体视觉升级，从当前粗糙的自定义样式升级为极简白净风格，提升专业感和用户体验。

## 2. 设计决策

| 维度 | 决策 | 理由 |
|------|------|------|
| 设计目标 | 整体视觉升级 | 当前页面样式粗糙，缺乏专业感 |
| 视觉风格 | 极简白净（Claude 风格） | 干净专业，阅读体验好 |
| 侧边栏 | 浅色融合 | 与主区域整体感更强 |
| 欢迎页 | 极简输入式 | 减少视觉干扰，聚焦核心功能 |
| 文件管理 | 侧边栏精简列表 | 保留全局资料库特性，同时不占过多空间 |
| 品牌色 | 琥珀金 `#d97706` | 温暖专业，与暖白背景搭配和谐 |

## 5. 侧边栏设计

### 5.1 结构（从上到下）

1. **品牌区**：Logo（28x28 圆角 6px，琥珀金底白字 "RA"）+ "RaceAgent" + "竞赛 AI 助手"
2. **新建对话按钮**：白底，边框 `#e8e5e0`，圆角 8px
3. **会话列表**：选中态 `#f5f0e8` 背景 + 琥珀金文字，未选中态无背景
4. **分隔线**：1px solid `#e8e5e0`
5. **资料库区**：标题 "📁 资料库 (N)"，最多显示 3 个文件，超出折叠
6. **分隔线**
7. **模型选择**：显示当前模型名称

### 5.2 交互

- 会话列表：点击切换会话，选中态高亮
- 资料区：点击标题可折叠/展开
- 文件上传：点击 "上传新文件" 触发 Streamlit file_uploader
- 文件删除：hover 显示删除按钮

## 6. 欢迎页设计

### 6.1 空状态

- 居中显示
- 品牌名：13px，font-weight 600，琥珀金色
- 大标题：26px，font-weight 600，"你好，我是 RaceAgent"
- 副标题：14px，color #888，"竞赛 AI 助手，帮你分析规则、制定计划"
- 输入框：宽度 560px，圆角 12px，边框 `#e8e5e0`，背景 `#faf9f7`

### 6.2 对话状态

- 欢迎页消失，显示对话内容
- 输入框固定在底部

## 7. 对话区设计

### 7.1 用户消息

- 右对齐
- 背景 `#f0f4ff`，圆角 16px，内边距 12px 16px
- 字号 15px，行高 1.6
- 最大宽度 72%

### 7.2 AI 回答

- 左对齐，无边框
- 纯文本展示，字号 15px，行高 1.85
- 使用 `st.markdown` 渲染

### 7.3 引用来源

- 显示在回答下方
- 分隔线：1px solid `#f0f0f0`
- 标题：12px，font-weight 600，color #888
- 来源项：12px，color #888，显示文件名和相似度

### 7.4 输入框

- 固定底部
- 圆角 12px，边框 `#e8e5e0`
- 背景 `#faf9f7`
- 带发送按钮（↑ 图标）

## 13. 实施范围

### 修改文件

- `frontend/app.py` — 主要修改，重构 CSS 和布局
- `frontend/static/styles.css` — 清理旧样式，应用新样式

### 不修改

- 后端代码（无变动）
- API 接口（无变动）
- 数据结构（无变动）

### 约束

- 保持 Streamlit 单文件架构
- 不引入新的前端框架
- 保持所有现有功能（上传、问答、任务拆解、会话管理）
- 保持中文文件名支持
- 保持 Docker 运行方式
